# Akili Runtime v0.1 public alpha

This first public release packages:

- a small installable local lifecycle runtime;
- explicit scoped memory admission;
- active/superseded versioning;
- provenance and hash-chained audit;
- a CLI that produces an agent context bundle;
- architecture and claims documentation;
- frozen research and systems evidence assets;
- specifications for the coding-agent API/MCP layer and Isaac Lab flagship.

The public alpha is not yet a complete coding agent and does not call an LLM. The next release will add the service API, MCP server and repository adapter.
