# Public and private boundary

## Public repository

- local lifecycle runtime;
- scope isolation, explicit admission, supersession and audit;
- Python SDK and CLI;
- basic MCP server when ready;
- controlled demos and reproducibility packages;
- architecture, results, limitations and security guidance;
- public adapters sufficient for developers to evaluate the project.

## Private commercial repository

- hosted Akili Cloud and tenancy infrastructure;
- authentication, billing, encryption and enterprise access controls;
- advanced retrieval, ranking and memory-quality controllers;
- private-repository connectors and managed coding-agent orchestration;
- production SOC/security and energy workflows;
- premium robotics, Isaac and edge deployment components;
- operational monitoring, customer analytics and support tooling;
- customer data, configurations and proprietary integrations;
- future neural continual-learning controller until a deliberate publication decision is made.

## Open-core rule

The public repository is Apache-2.0 and may be used commercially. Revenue comes from hosted operation, integrations, security, enterprise controls, support, private extensions and vertical products—not from contradicting the public licence.
