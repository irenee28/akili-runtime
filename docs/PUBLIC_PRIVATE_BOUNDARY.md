# Public/private boundary

## Public repository

The public repository contains everything required to verify published claims:

- runtime interfaces and tests;
- frozen experiment code;
- declared baselines;
- immutable result bundles;
- configuration and environment files;
- architecture and limitations;
- reproducibility instructions;
- result hashes and audit receipts.

## Private repository

The private repository contains commercial and unfinished material:

- pilot designs and pricing hypotheses;
- company-specific integrations;
- outreach lists and email drafts;
- customer data and deployment configuration;
- unfinished experiments and debugging lineage;
- proprietary validators or optimization work developed for a paid pilot;
- internal claim and risk ledgers.

The boundary is **evidence versus commerce**, not weak code versus strong code. Hiding reproducibility prevents trust; publishing customer strategy and unfinished integrations weakens commercial leverage.
