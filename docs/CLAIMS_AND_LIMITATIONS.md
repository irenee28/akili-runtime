# Claims and limitations

## Claims we can make

- Akili is a scoped, versioned and auditable procedural-memory runtime for AI agents.
- In controlled multi-file repository experiments with executable hidden tests, Akili completed 144/144 development and frozen held-out tasks while reducing prompt history by approximately 77.5%.
- In a separate verified-contract transport protocol across Qwen3-4B and Mistral Nemo, Akili completed 432/432 development and frozen held-out tasks with approximately 78% prompt reduction and zero stale or cross-scope retrievals.
- The deterministic lifecycle engine completed a 500,000-episode stress run with bounded state and a valid audit chain.

## Claims we must not make

- Akili is the best memory system in the world.
- Akili has solved neural continual learning or catastrophic forgetting.
- V4 generation passed.
- E2.2 proves autonomous coding or program synthesis.
- The controlled repository fixtures represent arbitrary public repositories.
- Mac Horizon proves production concurrency, distributed storage, networking or model quality.

## Result separation

| Protocol | Question | Result |
|---|---|---|
| V4 generation | Generate implementations from restored structural conventions | Frozen near-miss: 101/108 held-out |
| V4-MA-E2.2 transport | Restore and transport complete verified executable procedures | Complete pass: 432/432 across two models |

Combining them into a single perfect narrative would be inaccurate.
