# Frozen evidence portfolio

These results must remain separate. They answer different questions.

## Tier 1: controlled real-repository coding agent

- Development and frozen held-out combined: **144/144 Akili successes**.
- Bounded ICL: **72/144 (50%)**.
- Stateless: **42/144 (29.17%)**.
- Approximate prompt reduction: **77.46%**.
- Evaluation used executable hidden tests in controlled multi-file Python repository fixtures.
- The held-out hidden-test hash differed from development.

**Claim supported:** Akili retained and applied repository-specific corrections and conventions in a controlled coding-agent setting.

**Boundary:** these were controlled fixture repositories, not arbitrary public GitHub repositories.

## Tier 2: V3.1.1a procedural memory

- Frozen held-out code tasks: Akili **57/57**, bounded ICL **50/57**, stateless **3/57**.
- SOC held-out: Akili recall **70.4%**, specificity **96%**; bounded ICL recall **40.7%**, specificity **77.8%**.
- Approximate prompt reduction: **88.1%**.
- All 22 protocol gates passed.

**Claim supported:** immediate teaching, scoped restoration, specificity, lifecycle governance and bounded prompts.

## Tier 3: V4-MA-E2.2 verified-contract transport

Across Qwen3-4B and Mistral Nemo, development plus frozen held-out:

- Akili: **432/432** total successes.
- Restoration: **144/144**.
- Approximate prompt reduction: **78%**.
- Obsolete retrievals: **0**.
- Cross-scope retrievals: **0**.
- Semantic repairs in the final runs: **0**.

**Claim supported:** Akili can restore and efficiently transport the currently active verified executable procedure across two model families.

**Mandatory boundary sentence:** This experiment evaluates verified procedure restoration and transport, not autonomous program synthesis.

## Tier 4: V4 external structural generation

- Development: 102/108 Akili successes; formal development pass.
- Frozen held-out: **101/108 (93.52%)**.
- One performance criterion was missed; formal overall result: **near-miss / fail**.
- All seven held-out failures were in `artifact_naming`.
- Memory integrity passed: correct active template, zero stale retrieval and zero cross-scope retrieval.

Permanent attribution:

> Post-run analysis found both an underspecified interface around argument roles and genuine model-generation errors. The frozen result was not modified or rerun.

**Integrity rule:** never present E2.2 as a repair that turns V4 into a pass.
