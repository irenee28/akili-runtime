# Security policy

Do not report model-behavior weaknesses through a public issue when they include sensitive data, credentials, customer information, or a reusable exploit against a deployed system.

Send private security reports to **shukranimungu@gmail.com** with the subject line `Akili Security Report`.

The current repository is a research prototype. Hash chains are tamper-evident but do not replace secure storage, code signing, sandboxing, access control, independent attestation, or a complete production security review.
