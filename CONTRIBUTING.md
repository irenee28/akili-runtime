# Contributing

Thank you for helping improve Akili Runtime.

1. Open an issue before a large change.
2. Keep changes scoped and auditable.
3. Add tests for lifecycle, scope isolation and supersession behaviour.
4. Do not weaken evidence or security checks merely to improve a metric.
5. Do not merge the V4 generation result with the V4-MA-E2.2 transport result.
6. Run `python -m pytest` before submitting a pull request.

By contributing, you agree that your contribution is licensed under Apache License 2.0.
